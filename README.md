# IQ აკადემია — საიტი + მშობლების პორტალი

Next.js 14 + PostgreSQL (Prisma) + NextAuth.js აპლიკაცია.

## რა შედის პაკეტში

**საჯარო საიტი**
- `/` — მთავარი გვერდი
- `/services` — სერვისები
- `/about` — ჩვენ შესახებ
- `/contact` — კონტაქტი

**ავტორიზაცია**
- `/login` — შესვლა (ადმინი და მშობელი ერთი ფორმით)
- `/register` — მშობლის რეგისტრაცია (სახელი + ტელეფონი/ემაილი + პაროლი + "მოსწავლის კოდი")

**მშობლის კაბინეტი**
- `/dashboard` — დაკავშირებული შვილ(ებ)ის დღიური აქტივობა და კვირის შეფასებები

**ადმინის პანელი**
- `/admin` — მოსწავლეების სია და დამატება
- `/admin/students/[id]` — კონკრეტული მოსწავლისთვის დღიური აქტივობის და კვირის შეფასების დამატება, ისტორიის ნახვა, დაკავშირებული მშობლების ნახვა

## როგორ მუშაობს მშობლის დაკავშირება მოსწავლესთან

1. ადმინი `/admin`-ზე ამატებს მოსწავლეს (სახელი + კლასი) — სისტემა ავტომატურად აგენერირებს უნიკალურ **მოსწავლის კოდს** (მაგ. `A1B2C3`).
2. ადმინი ამ კოდს აწვდის მშობელს (პირადად, SMS-ით ან ემაილით).
3. მშობელი `/register`-ზე რეგისტრირდება საკუთარი მონაცემებით და შეყავს ეს კოდი — ავტომატურად უკავშირდება შვილის პროფილს.
4. ერთ მშობელს შეუძლია რამდენიმე შვილის კოდიც შეიყვანოს (თითო რეგისტრაცია ერთ კოდს უკავშირდება — მეორე შვილისთვის დაამატეთ მეორე ბმის მექანიზმი საჭიროებისამებრ, ან მომმართეთ დამატებითი "დაამატე შვილი" გვერდის ასაშენებლად).

## ლოკალურად გაშვება

1. დააინსტალირეთ დამოკიდებულებები:
   ```bash
   npm install
   ```
2. შექმენით `.env` ფაილი `.env.example`-ის მიხედვით და შეავსეთ:
   - `DATABASE_URL` — PostgreSQL კავშირი (იხ. ქვემოთ, "ბაზის მიღება")
   - `NEXTAUTH_SECRET` — გენერაცია: `openssl rand -base64 32`
   - `NEXTAUTH_URL` — `http://localhost:3000`
3. გადაატარეთ ბაზის სქემა:
   ```bash
   npx prisma migrate dev --name init
   ```
4. შექმენით პირველი ადმინი (მონაცემები აიღება `.env`-დან `ADMIN_*` ცვლადებით):
   ```bash
   npm run seed
   ```
5. გაუშვით:
   ```bash
   npm run dev
   ```
   საიტი ხელმისაწვდომია `http://localhost:3000`-ზე. ადმინით შედით `/login`-ზე `.env`-ში მითითებული ემაილითა და პაროლით.

## ბაზის მიღება (რეკომენდებული: Neon, უფასო)

1. შედით [neon.tech](https://neon.tech) (ან [supabase.com](https://supabase.com)) და შექმენით უფასო ანგარიში.
2. შექმენით ახალი პროექტი/ბაზა — ავტომატურად მოგცემთ `DATABASE_URL`-ს, დააკოპირეთ ის.
3. ჩასვით `.env`-ში (ლოკალურად) და Vercel-ის environment variables-ში (production-ისთვის, იხ. ქვემოთ).

## დეპლოი: Vercel (აპლიკაცია) + Hostinger (დომენი)

**რატომ ასე:** Vercel სპეციალურად აგებულია Next.js-ისთვის — უფასო, ავტომატური, SSH არ სჭირდება. Hostinger-ზე ნაყიდი დომენი უბრალოდ "მიმართავთ" Vercel-ისკენ DNS ჩანაწერით — hosting-ის ადგილი დაკარგული არაა, უბრალოდ თავად აპლიკაცია სხვაგან მუშაობს.

**1. ატვირთეთ პროექტი GitHub-ზე** (თუ ჯერ არ გაქვთ — შექმენით უფასო რეპოზიტორია და აატვირთეთ ეს ფოლდერი).

**2. დააკავშირეთ Vercel-თან:**
- შედით [vercel.com](https://vercel.com), შედით GitHub ანგარიშით
- "Add New Project" → აირჩიეთ თქვენი რეპოზიტორია → Import

**3. Environment Variables** (Vercel-ის პროექტის დაყენებისას დაამატეთ):
   - `DATABASE_URL` — Neon-დან აღებული სტრიქონი
   - `NEXTAUTH_SECRET` — გენერაცია: `openssl rand -base64 32` (ან ნებისმიერი შემთხვევითი 32+ სიმბოლოიანი სტრიქონი)
   - `NEXTAUTH_URL` — თქვენი საბოლოო დომენი, მაგ. `https://iqacademy.ge`

**4. Deploy** — დააჭირეთ ღილაკს, 1-2 წუთში მზად იქნება (დროებით `xxx.vercel.app` მისამართზე).

**5. ცხრილების შექმნა ბაზაში** — ლოკალურად, `.env`-ში Neon-ის `DATABASE_URL`-ით:
   ```bash
   npx prisma migrate deploy
   npm run seed
   ```
   (ეს ქმნის ცხრილებს production ბაზაში და პირველ ადმინის ანგარიშს.)

**6. დომენის მიბმა — Hostinger-დან Vercel-ისკენ:**
   - Vercel-ის პროექტში: Settings → Domains → დაამატეთ `iqacademy.ge` (თქვენი დომენი)
   - Vercel გაჩვენებთ ზუსტად რა DNS ჩანაწერები გჭირდებათ (ჩვეულებრივ ერთი `A` ჩანაწერი root დომენისთვის და `CNAME` — `www`-სთვის)
   - შედით Hostinger hPanel → Domains → თქვენი დომენი → DNS/Nameservers → დაამატეთ ეს ჩანაწერები
   - რამდენიმე საათში (ხშირად უფრო სწრაფად) დომენი აქტიური იქნება და Vercel ავტომატურად გასცემს უფასო HTTPS სერტიფიკატს

ამის შემდეგ, ნებისმიერი მომავალი ცვლილება (ტექსტი, ფუნქცია, დიზაინი) უბრალოდ კოდის განახლება და `git push` არის — Vercel თავად გადააშენებს საიტს ავტომატურად.

**თუ მაინც გსურთ ყველაფერი Hostinger-ზე ჰქონდეთ** (ერთ ადგილას, MySQL-ით და Node.js Apps ფუნქციით), ეს შესაძლებელია, მაგრამ საჭიროებს `schema.prisma`-ში `provider`-ის შეცვლას `"mysql"`-ზე და SSH წვდომას migration-ების გასაშვებად — მითხარით, თუ ამ გზას აირჩევთ და დაგეხმარებით.

## რჩევები შემდეგი ეტაპისთვის

- **კონტაქტის ფორმა** ამჟამად იყენებს `mailto:`-ს (იხსნება მომხმარებლის ემაილ კლიენტი). რეალურ პროდაქშენში სჯობს ჩაანაცვლოთ API endpoint-ით (მაგ. Resend, SendGrid) რომ პირდაპირ თქვენს ინბოქსში მოხვდეს.
- **პაროლის აღდგენა** ("დაგავიწყდათ პაროლი") არ არის ჩართული — შემდეგ ეტაპზე ადვილად დაემატება NextAuth-ის საშუალებით.
- **სურათები/ლოგო** — ამჟამად დიზაინი ტექსტურია; შეგიძლიათ დაამატოთ ლოგო და ფოტოები `public/` საქაღალდეში და გამოიყენოთ `next/image`.
- **SMS/ემაილის შეტყობინებები** ახალი შეფასების დამატებისას — შემდეგი ეტაპისთვის კარგი დამატება იქნება (Twilio/SendGrid ინტეგრაცია).
- **მრავალშვილიანი მშობლის რეგისტრაცია** ერთდროულად — ამჟამად ერთი კოდი ერთი რეგისტრაციისას; ადვილად გავაფართოვებთ საჭიროებისამებრ.
